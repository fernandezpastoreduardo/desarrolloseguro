# Documentación de Desarrollo Seguro

Esta carpeta reúne documentación técnica del proyecto independiente Desarrollo Seguro.

> **Estado de esta documentación:** los documentos actuales explican la versión anterior del proyecto. El reinicio está pendiente de toma de requisitos y plan acordado; por tanto, estas páginas no describen todavía el producto objetivo. Se actualizarán al completar cada feature nueva.

## Guías

- [Desarrollo local](development.md): requisitos, comandos y comprobaciones.
- [Stack](stack.md): versiones y estructura del proyecto.
- [CI](ci-cd.md): verificaciones automatizadas.
- [Credenciales](credentials.md): secretos necesarios para operar el stack propio.
- [Producción](production.md): topología Docker aislada y preparación manual.
- [Verificación](verification.md): alcance y límites de las comprobaciones actuales.
- [Historial público](public-report-history.md): contrato del historial acotado y comparabilidad de informes.
- [Calidad](quality-baseline.md): criterios de calidad.
- [Alcance del producto](desarrollo-seguro.md): propósito, estado y límites del prototipo.

Las directrices de implementación están en [`agentic-guidelines/`](../agentic-guidelines/). No se almacenan aquí claves, contraseñas ni datos de usuarios.
