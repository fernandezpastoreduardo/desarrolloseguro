MÉTODO Y CRITERIOS

Un informe debe explicar qué se comprobó.

El análisis revisa una dirección HTTPS concreta y reúne la evidencia, la fecha y los límites de cada comprobación.

01 / EL RECORRIDO

De una dirección web a una lectura documentada.

El informe distingue lo que se observó de lo que quedó sin comprobar. Una nota resume solo los criterios con evidencia suficiente; no certifica todo el servicio ni sustituye una revisión completa.

  1. 01

    Definición del objetivo

    Se indica una URL HTTPS completa. La comprobación se limita a las rutas y recursos que admite el perfil; no busca redes privadas ni paneles de acceso.

    OBJETIVO
  2. 02

    Comprobaciones visibles

    Se revisa cómo se localiza el sitio, si la conexión protege los datos, cómo responde el servidor y qué barreras recibe el navegador.

    EVIDENCIA
  3. 03

    Evaluación y contexto

    Cada criterio indica si se cumple, si no se cumple o si no se pudo comprobar. La falta de datos no cuenta como resultado favorable ni se atribuye al sitio cuando falla la comprobación.

    CRITERIO
  4. 04

    Informe consultable

    El informe reúne los resultados disponibles, la fecha, las rutas revisadas y las limitaciones para que puedan contrastarse.

    INFORME
i

Cómo leer la puntuación

La valoración resume únicamente criterios con evidencia disponible. No convierte la ausencia de datos en una señal positiva, y una puntuación aislada nunca debe leerse como garantía de seguridad o privacidad.
