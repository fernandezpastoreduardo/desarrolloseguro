Qué incluirá un informe y qué falta para ofrecerlo

El alcance inicial se limita a la portada del dominio consultado. Cada informe indicará las rutas y controles observados, junto con el origen y las limitaciones de la medición.

Antes de activar análisis reales faltan pruebas de pinning DNS/IP, aislamiento de red y capacidad. La interfaz de consulta está disponible en Desarrollo Seguro, pero el servicio aún no ejecuta análisis ni guarda informes reales. Esta página no muestra fechas, puntuaciones ni resultados ficticios.

Caso de uso · Superficie web pública

Evidencias claras, con sus límites a la vista.

Desarrollo Seguro consulta informes existentes sobre controles observables desde fuera. La consulta no inicia análisis ni convierte una observación técnica en una certificación.

  • ✓Alcance explícito. Cada informe enumera las rutas y los controles comprobados.
  • ✓Resultados con evidencia. Los datos públicos se proyectan sin exponer evidencia privada.
  • ✓Límites verificables. Los controles no observables se presentan como desconocidos o no evaluables.
  • ↗Trabajo pendiente. El executor de red y las pruebas de aislamiento siguen bloqueados hasta superar sus gates.

El estado actual es una experiencia informativa y de demostración. No constituye una certificación, una auditoría independiente ni una garantía de ausencia de vulnerabilidades.
